# Статистика экспериментов

У каждого эксперимента на вкладке измерений есть кнопка «Дополнительная статистика». Она открывает модальное окно с выбором метрики, бэкенда и последних 5, 10, 30, 50 или 100 успешных измерений на каждую модель и бэкенд. Основная сводка остаётся прежней. При выборе бэкенда встроенная реализация остаётся видимой для сравнения.

## Расширенное окно

- **Обзор:** среднее и медиана с отдельными 95%-ми bootstrap-интервалами, стандартное отклонение, CV, p95, границы выборки, пропуски. Общий тест Краскела-Уоллиса с размером эффекта ε² = H/(N - 1), тест Левена с центром по медиане. Поправка Холма для общих тестов выполняется по доступным метрикам отдельно для каждого теста.
- **Распределение:** p5, p10, Q1, медиана, Q3, p90, p95, p99, p95/медиана, размах, выборочная дисперсия, SEM, IQR, MAD, робастная σ, усечённое среднее с 10 % с каждого края, геометрическое и гармоническое средние, асимметрия, эксцесс Фишера, Шапиро-Уилк, выбросы по 1,5 IQR, нули, число уникальных значений и ECDF.
- **Сравнения:** все уникальные пары, разности средних и медиан, отношение медиан A/B, изменение относительно B, δ Клиффа, приближённая поправка g Хеджеса, P(A < B) + ½P(A = B), расстояние Вассерштейна, Манн-Уитни, Уэлч, Левен. Холм применяется отдельно к каждому типу теста в пределах метрики. Дисперсии и g не определяются при недостаточных данных/нулевом знаменателе.
- **Тепловые карты:** семь представлений - δ, p Холм, отношение медиан, изменение медианы в процентах, g, Вассерштейн и вероятность меньшего значения. Матрицы включают все варианты; диагональ p не тестируется. Экспорт карты в SVG.
- **Связи и стабильность:** корреляции Спирмена и Пирсона между метриками внутри выбранного варианта по совместно заполненным записям, таблица значимости, график по порядку записей, наклон, ранговая корреляция с порядком, корреляция соседних значений и сдвиг медиан половин выборки. p Спирмена рассчитывается перестановками (1999, seed 0); Холм внутри варианта отдельно для каждого типа корреляции. Порядок по `created_at`, затем ID - это порядок записи в БД, не гарантированный порядок вызовов моделей. Диагностика тренда описательная, без заявления стационарности.

Все расчёты доступны в JSON с ID выбранных измерений; показатели выбранной метрики выгружаются в CSV. Постоянные ряды не получают искусственную корреляцию, пропуски не превращаются в нули, выбросы не удаляются. CV требует положительного среднего, отношения - положительного знаменателя, геометрическое и гармоническое средние - положительных наблюдений. Шапиро-Уилк не применяется к постоянной выборке; p ≥ 0,05 не доказывает нормальность. На малых выборках перцентили и тесты требуют осторожной интерпретации.

API дополнительно возвращает `diagnostics` (распределения, корреляции, последовательности и тренды), `omnibus` и описание методов. `backend/app/statistics_insights.py` отвечает за эти диагностики. Обычный ответ агента сохраняет компактный прежний набор полей, чтобы расширенные таблицы не превышали лимит контекста инструмента; полный отчёт доступен в модальном окне и API.

## Базовые расчёты и совместимость

Количество прогонов основной сводки выбирается отдельно: 5, 10, 20, 30, 50 или 100. Выбор бэкенда применяется к библиотечной карточке; встроенный вариант сохраняется для сравнения. Число прогонов не дописывается в скобках к стандартному отклонению.

Сравнения показаны матрицей «все варианты со всеми»: A обозначен строкой, B - столбцом. В обратной ячейке знак дельты Клиффа меняется, p-value остаётся прежним. Диагональ не тестируется. В каждой метрике проверяются все уникальные пары; поправка Холма не удваивается из-за отображения обеих сторон матрицы. Фильтр бэкенда действует только на верхнюю таблицу показателей, матрица остаётся полной. Исходный список уникальных пар доступен под матрицей.

Для метрик рассчитываются медиана, среднее, минимум, максимум, выборочное стандартное отклонение, p95, межквартильный размах (IQR) и 95%-й доверительный интервал медианы. Интервал получен percentile bootstrap по отдельным измерениям: 2000 выборок, seed 0. При одном значении интервал отсутствует; у постоянной выборки он совпадает с её значением. Такой интервал не учитывает зависимость вызовов между повторными вызовами.

В модальном окне показаны дельта Клиффа, двусторонний p-value Манна-Уитни и p-value с поправкой Холма отдельно для каждой метрики. Сравниваются отдельные измерения; при менее двух значениях на группу p-value отсутствует. При малых выборках с совпадающими значениями используется перестановочный вариант теста; при отсутствии совпадений - точный вариант для малой выборки, иначе асимптотический. Полностью одинаковые значения дают δ=0 и p=1 при достаточном числе наблюдений. Поправка Холма рассчитана по всем сравнениям вариантов одной метрики в загруженном окне, независимо от фильтра отображения.

Дельта определена как `P(A > B) - P(A < B)` и лежит в пределах от -1 до 1. Отрицательное значение означает меньшие значения у A. Это не процент ускорения. Тест предполагает независимые измерения; стенд не проверяет автоматически одинаковые входы и окружение. Зависимые повторы могут преувеличивать значимость.

API: `GET /api/measurements/statistics?experiment_key=...&window=30`. Возвращает `groups`, `comparisons`, ID использованных измерений и описание метода. Существующий `/summary` сохранён для совместимости.

Агент использует тот же модуль `backend/app/experiment_statistics.py` через `calculate_statistics`. Его выборка ограничена параметром `limit` глобально (по умолчанию 100, максимум 500), а UI ограничивает каждую группу отдельно. Поэтому для проверки совпадения чисел нужно сопоставлять ID и состав выборки. Пример запроса: «Рассчитай p95, IQR, доверительные интервалы, дельту Клиффа и p-value для text_classification». Числовой ответ формируется из результатов инструмента, без пересчёта языковой моделью.


Описание используемых методов: [Mann-Whitney U](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.mannwhitneyu.html), [bootstrap](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html).
