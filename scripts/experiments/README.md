# Эксперимент по определению тональности

Команды выполняются из корня репозитория. Это отдельный эксперимент из п. 5.4 отчёта, а не набор проверок приложения.

```sh
node scripts/experiments/run-sentiment-experiment.mjs
python scripts/experiments/analyze-sentiment-experiment.py artifacts/sentiment-experiment/RUN_ID exports/sentiment-RUN_ID
```

Для запуска нужны зависимости frontend, Chrome, локальные веса USE (`python scripts/fetch-models.py`). Для анализа нужны NumPy, SciPy и Matplotlib из зависимостей backend. Вместо `RUN_ID` укажите каталог, напечатанный запуском.

Запуск использует отдельные Chrome и Vite, четыре фиксированных текста, пять кругов со случайным порядком конфигураций и seed 42. Проверяются доступные CPU, WASM, WebGL, WebGPU и Gemini Nano. Недоступные варианты исключаются до составления расписания. Перед каждой парой измерений выполняются 20 прогревочных вызовов. Результаты сохраняются в `artifacts/sentiment-experiment/`; в БД скрипт их не отправляет.

По умолчанию открывается окно браузера, которое необходимо держать активным. Путь к Chrome задаётся через `CHROME_BIN`. Для диагностики доступности можно передать `--probe-only`; для headless-запуска - `--headless`. Ключ `--skip-nano` пропускает подготовку недоступной модели Nano, но уже доступная модель всё равно участвует.

Анализ требует завершённый запуск (`complete.json`), рассчитывает показатели, сравнения и строит графики. Выходной каталог должен отличаться от входного.
