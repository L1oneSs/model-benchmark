# Локальные веса TensorFlow.js

Веса не входят в репозиторий; подпапки моделей исключены из Git. По умолчанию модели загружаются библиотеками из внешних хранилищ.

Из корня проекта в Bash с `curl` и `python3`:

```sh
bash scripts/fetch-models.sh
```

Скрипт скачивает `model.json` и шарды его `weightsManifest`:

| Папка | Что скачивается | Использование текущим адаптером |
|---|---|---|
| `model-a` | MobileNet v2 1.0 224 | Используется при `VITE_MODEL_SOURCE=local` |
| `model-b` | Universal Sentence Encoder lite | Скачивается скриптом, но текущий `use.load()` не использует эту папку |

Чтобы переключить MobileNet, задайте в корневом `.env`:

```env
VITE_MODEL_SOURCE=local
```

И пересоберите фронтенд:

```sh
docker compose up -d --build --no-deps frontend
```

MobileNet берётся по `/models/model-a/model.json` в классификации изображения и эксперименте ускорителей. Метрика первой загрузки всё равно включает чтение весов, инициализацию и внутренний прогрев, а не становится нулевой автоматически.

**Этот режим не делает весь стенд автономным.** USE продолжает вызывать `use.load()` без локального пути; Toxicity, MobileBERT, COCO-SSD и Face Detector тоже загружаются через библиотеки. Transformers.js / ONNX скачивает веса из Hugging Face и использует свой кеш. Встроенные модели и языковые пакеты скачивает Chrome. Ollama хранит отдельные серверные веса в Docker-томе.

Для полностью автономной работы понадобятся отдельная настройка источников всех моделей и проверка доступности их токенизаторов и runtime-файлов. Текущий `fetch-models.sh` этого не выполняет.
