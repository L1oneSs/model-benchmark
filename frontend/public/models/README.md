# Веса моделей TensorFlow.js

Папка пуста по умолчанию: стенд работает с `VITE_MODEL_SOURCE=cdn` и тянет веса
из официальных хранилищ Google при первом запуске эксперимента.

Чтобы стенд не зависел от внешней сети — а для чистоты эксперимента это лучше,
потому что сетевая задержка перестаёт попадать в метрику загрузки, — скачайте
модели локально:

```bash
bash scripts/fetch-models.sh
```

Скрипт положит сюда:

| Папка     | Модель                             | Где используется                      |
|-----------|------------------------------------|---------------------------------------|
| `model-a` | MobileNet v2 1.0 224               | классификация изображений             |
| `model-b` | Universal Sentence Encoder lite    | векторизация текста для классификации |

После загрузки поставьте `VITE_MODEL_SOURCE=local` в `.env` и пересоберите фронтенд:

```bash
docker compose up -d --build frontend
```

Содержимое подпапок игнорируется гитом: веса весят десятки мегабайт и в
репозитории им не место.
