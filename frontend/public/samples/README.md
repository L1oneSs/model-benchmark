# Тестовые изображения

`test-pattern.png` — синтетический паттерн 224x224, тот же размер, что MobileNet
ожидает на входе. Содержание картинки на латентность не влияет, но
зафиксированный вход делает прогоны воспроизводимыми.

Для содержательных предсказаний (когда важна не только скорость, но и то, что
именно распознали обе модели) положите сюда свои фотографии и выбирайте их
кнопкой «Выбрать своё изображение» в карточке эксперимента.
