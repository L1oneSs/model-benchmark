# Тестовые изображения

Изображения раздаются фронтендом по `/samples/…`. В карточке можно загрузить собственную фотографию; загрузка файла на сервер для экспериментального инференса не требуется.

| Файл | Назначение |
|---|---|
| `test-pattern.png` | Синтетический вход 224 × 224 по умолчанию для классификации изображения и сравнения ускорителей |
| `object-detection.jpg` | Вход обнаружения объектов: люди и воздушные змеи на пляже |
| `faces-group.jpg` | Вход подсчёта лиц: групповая фотография |
| `face-counting.jpg` | Сохранённый прежний образец; текущий реестр экспериментов не использует его по умолчанию |

`faces-group.jpg` взят из [тестовых данных TensorFlow.js](https://github.com/tensorflow/tfjs-models/blob/master/shared/test_data/three_people.jpg).

`object-detection.jpg` взят из [демо COCO-SSD](https://github.com/tensorflow/tfjs-models/blob/master/coco-ssd/demo/image1.jpg). Репозиторий tfjs-models распространяется под Apache-2.0.

Синтетический паттерн предназначен прежде всего для воспроизводимого сравнения латентности, а не для проверки содержательного распознавания объектов. Размер и содержимое входа могут влиять на инференс и результат; для сравнения подходов используйте одну и ту же картинку и фиксируйте параметры среды.

Стенд отображает найденные классы/количество лиц и объектов, но не спрашивает правильное число лиц и не вычисляет автоматическую точность по эталонной разметке. Gemini требует поддержки изображений в Prompt API; иначе сохраняется `unsupported`.
