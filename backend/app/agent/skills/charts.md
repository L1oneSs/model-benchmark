# Measurement charts: построение графиков

## 1. Назначение и результат

Преобразуй сохранённые измерения в проверяемое визуальное сравнение.
Результат — график с названием эксперимента, метрикой, единицами и фактическим
числом наблюдений. Python-форматы дополнительно возвращают ссылку на файл.

## 2. Обязательный протокол выполнения

<!-- runtime:start -->
Для графика вызывай build_chart. Разреши experiment_key по каталогу и сохраняй
только явно запрошенные фильтры модели/бэкенда/серии.

renderer: html — HTML/CSS в чате по умолчанию;
python_static — Python/статичный/PNG/Matplotlib;
python_interactive — динамический/интерактивный/Plotly.
Динамический означает наведение и масштабирование, не live-обновление или анимацию.
Текущий вид только горизонтальный bar; line/scatter/boxplot/гистограмма не реализованы.

metric: inference_ms по умолчанию; first_token_ms — первое предсказание;
load_ms — загрузка; total_ms — полное время; memory_mb — JS heap.
«Все метрики» → metric=all одним вызовом, отдельный график каждой доступной метрики.
statistic: median по умолчанию, mean для среднего. Не меняй запрошенный формат.

Используй только charts инструмента, не генерируй HTML/JS/Python/SVG самостоятельно.
Группы разделены по модели/бэкенду/парадигме. Покажи фактическое samples.
Не смешивай мс и МБ на одной оси. Пропуск не равен нулю; ноль и отрицательная
разница JS heap допустимы. Сообщи missing_metrics и truncated.

Python-файл существует только при artifact_url. При пустых points не обещай файл.
Не выдумывай ссылку, диаграмму, значения, экспорт или дополнительные форматы.
График описывает выбранные записи, а не универсальную скорость технологии.

## 3. Выбор представления

| Запрос пользователя | renderer | Что увидит пользователь |
|---|---|---|
| «В чате», «HTML», формат не указан | `html` | Диаграмма интерфейса |
| «Python статично», «PNG», «Matplotlib» | `python_static` | PNG и ссылка на файл |
| «Python динамически», «Plotly», «интерактивно» | `python_interactive` | Интерактивный HTML и ссылка |

Статичный вариант подходит для сохранения изображения. Интерактивный —
для исследования значений, наведения и масштабирования.
Самостоятельный HTML включает Plotly.js и не требует CDN.
Удаление файлов артефактов делает старые ссылки из истории недоступными.

## 4. Контракт вызова

Учебный пример, не реальные данные:

```json
{
  "experiment_key": "text_classification",
  "metric": "inference_ms",
  "statistic": "mean",
  "renderer": "python_static",
  "backend": "webgpu",
  "limit": 100
}
```

`limit` по умолчанию 100, максимум 500; фильтры совпадают с инструментом статистики.
Не указывай backend, model_name или run_index, если пользователь их не просил.

## 5. Выбор метрики

| Смысл запроса | metric | Единица |
|---|---|---|
| Инференс, латентность | `inference_ms` | мс |
| До первого результата | `first_token_ms` | мс |
| Загрузка | `load_ms` | мс |
| Полное время | `total_ms` | мс |
| Память | `memory_mb` | МБ |
| Все измеряемые метрики | `all` | Отдельные графики |

Память означает JS heap. Медиана и среднее являются разными агрегатами:
название и описание графика должны соответствовать выбранному показателю.

## 6. Проверка результата инструмента

1. Проверь `charts` и непустые `points`.
2. Сопоставь возвращённые метрики с запросом.
3. Проверь `unit`, `statistic` и `renderer`.
4. Сообщи отсутствующие метрики из `missing_metrics`.
5. При `truncated=true` объясни ограничение выборки.
6. У Python-формата используй только возвращённый `artifact_url`.
7. Не заменяй ошибку рендеринга заявлением о готовом графике.

## 7. Формат сопровождающего ответа

Кратко назови эксперимент, показатель и формат.
График отображает клиент; текст ответа не должен дублировать каждую точку.
Существенные ограничения данных перечисли рядом с графиком и процитируй источник.

## 8. Контрольные ситуации

| Запрос/условие | Ожидаемое поведение |
|---|---|
| Среднее в Python PNG | `mean`, `python_static` |
| Все метрики интерактивно | `all`, `python_interactive` |
| Нет загрузки модели | Перечислить пропуск, не рисовать выдуманный ноль |
| Нужен live-график | Объяснить отсутствие автоматического обновления |
| Запрошена гистограмма | Объяснить ограничение доступного вида |
| Отрицательная память | Сохранить значение и шкалу с нулём |

## 9. Финальный контроль

- [ ] Эксперимент, формат и агрегат совпадают с запросом.
- [ ] Метрики разных единиц разделены.
- [ ] Значения и n взяты из инструмента.
- [ ] Пропуски и ограничение выборки обозначены.
- [ ] Файл и ссылка действительно возвращены, если они обещаны.
